📒 Agenda de Contatos — Django

Aplicação web desenvolvida com Django para gerenciamento de contatos pessoais ou corporativos.
Permite cadastrar, editar, visualizar, buscar e excluir contatos de forma simples e eficiente.

🚀 Tecnologias Utilizadas

Python 3.10+

Django 

SQLite 

HTML5 + CSS3

Bootstrap 

📌 Funcionalidades

✅ Cadastro de contatos

✅ Listagem paginada

✅ Busca por nome, email ou telefone

✅ Atualização de dados

✅ Exclusão de contatos

✅ Validação de formulário

✅ Interface responsiva
